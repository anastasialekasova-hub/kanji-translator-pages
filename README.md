# Kanji Translator — pages

Welcome, uninstall and feedback pages for the Kanji Translator Chrome extension, served via GitHub Pages.

- `/welcome/` — opens once after installation
- `/uninstall/` — feedback form, opens when the extension is removed
- `/feedback/` — one-question form for a 1–3 star rating in the popup
- privacy policy lives on pinwisp.com: https://pinwisp.com/kanji-translator/privacy/
